## Why

Старый проект (`leaderboard.zip`) при всей примитивности имел лучшую страницу обоих проектов — деталку модели с графиком динамики Elo — и более разговорчивые рекомендации пар. Все данные для этого уже лежат в `index.json` (`elo_history`, модели), т.е. заимствование сводится к отображению без смены формата данных.

## Что меняется

- Страница модели (`/model/<id>`): SVG-график динамики Elo без JS-библиотек (точки `after` каждого матча + старт, подписи min/max/текущий), H2H-секция по соперникам (встреч / W / L / D / winrate), личная история матчей (`соперник / исход / Elo до / Δ / после / дата`). Ссылка с имени модели в лидерборде.
- Рекомендации пар: строка-обоснование (`reason`: «не встречались» / «счёт A:B, Δ=N») + кнопка «Принять пару» — предзаполняет форму вердикта выбранными моделями.
- Строка-легенда под таблицей лидерборда: «Старт 1200 · K 40/32/24 · ничья 0.5».
- Подсветка топ-3 строк и отдельная серая секция скрытых/архивных моделей со счётчиком.
- Сознательно НЕ делаем (зафиксированные отказы владельца): обоснование судьи в вердиктах, UI-экспорт/импорт данных.

## Возможности

### Новые возможности

Нет новых spec-сущностей — только отображение существующих данных.

### Изменяемые возможности

- `leaderboard-ui`: новая страница модели, обоснование рекомендаций + apply-кнопка, легенда параметров, подсветка топ-3, секция скрытых. H2H и график — производные от уже хранимых `elo_history` и журнала вердиктов, формат данных не меняется.

## Влияние

- Код: `tools/server.py` (новые роуты/шаблоны), возможно `tools/render_helpers.py` (форматирование). `elo.py`, формат вердиктов, `index.json` не затрагиваются.
- Не зависит от переезда в `data/` по коду, но идёт третьим по очереди — чтобы UI писался уже на финальных путях.
