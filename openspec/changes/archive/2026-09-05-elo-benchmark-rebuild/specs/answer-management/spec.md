## Purpose

Хранение MD-ответов моделей на задачи. Ответ содержит анализ (текст) и код (в блоках ```). Модель пишет один MD-файл на задачу.

## ADDED Requirements

### Requirement: Формат ответа

Каждый ответ хранится в `answers/<task-id>/<model-id>.md`. Файл содержит YAML front matter (task, model, date) и тело ответа.

#### Scenario: Структура файла ответа

- **WHEN** модель claude-sonnet-4.5 отвечает на задачу T-001
- **THEN** создаётся файл `answers/T-001/claude-sonnet-4.5.md`
- **AND** front matter: { task: "T-001", model: "claude-sonnet-4.5", date: "YYYY-MM-DD" }

### Requirement: Содержание ответа

Тело ответа — Markdown с разделами: анализ, находки, код в блоках ```, план (если требуется). Модель SHOULD структурировать ответ с заголовками и списками.

#### Scenario: Ответ с кодом

- **WHEN** модель предлагает исправление бага
- **THEN** ответ содержит блок ```kotlin с исправленным кодом
- **AND** текстовое описание проблемы и решения

#### Scenario: Ответ с анализом без кода

- **WHEN** задача требует только анализ (без исправлений)
- **THEN** ответ содержит текстовый анализ с заголовками
- **AND** код может отсутствовать

### Requirement: Уникальность ответа

На одну задачу одна модель даёт один ответ. Перезапись возможна только при явном запросе (повторный прогон).

#### Scenario: Повторный прогон

- **WHEN** модель A уже имеет ответ на T-001, и пользователь запускает повторный прогон
- **THEN** файл answers/T-001/A.md перезаписывается
- **AND** вердикты с участием старого ответа остаются (ELO пересчитывается)

### Requirement: Шаблон ответа

Файл `answers/_TEMPLATE.md` содержит пустой шаблон с front matter и секциями.

#### Scenario: Создание ответа из шаблона

- **WHEN** модель начинает отвечать на задачу
- **THEN** промпт включает структуру из answers/_TEMPLATE.md
- **AND** модель заполняет секции своими находками

### Requirement: Проверка наличия ответа

Система проверяет наличие ответа модели на задачу перед: предложением пары, записью вердикта.

#### Scenario: Модель без ответа

- **WHEN** система предлагает пару для T-001, но модель C не имеет ответа
- **THEN** C не включается в кандидаты на сравнение

#### Scenario: Запись вердикта без ответа

- **WHEN** пользователь пытается записать вердикт A vs C на T-001, но C не имеет ответа
- **THEN** система отклоняет с ошибкой "У модели C нет ответа на задачу T-001"
