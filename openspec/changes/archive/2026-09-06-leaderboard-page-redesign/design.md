## Context

Главная страница в `tools/server.py` сейчас построена из блоков, идущих друг
за другом по вертикали: рекомендации, leaderboard, форма, история.
См. `proposal.md` — мотивация: сделать layout компактнее и убрать визуальный
шум от постоянно видимой истории.

## Goals / Non-Goals

**Goals:**
- Двухколоночный layout: слева leaderboard с фильтром, справа панель
  «Добавить результат» (рекомендации + форма вердикта).
- Сворачиваемый блок истории внизу с пагинацией по 20 записей.
- Адаптив: на узком экране колонки становятся вертикальной стопкой.
- Повторить тот же layout в `tools/generate_html.py`, но без формы
  (только справочная панель справа).

**Non-Goals:**
- Изменение логики ELO, pairing-алгоритма, генерации `index.json`.
- Изменение страниц `/add` и `/edit`.
- Изменение формата вердиктов и matchups.

## Decisions

- **CSS Grid для колонок**: `.main-layout { display: grid; grid-template-columns: 1.2fr 0.8fr; gap: 24px; }`,
  media `< 900px` → `grid-template-columns: 1fr`.
- **Рекомендации сверху правой панели, форма под ними**: кнопка «Прогнать»
  заполняет dropdowns, форма уже в поле зрения, не нужен `scrollIntoView`.
- **История — `<details>`/`<summary>`** для нативного сворачивания. Внутри
  рендерится только текущая страница. Пагинация — GET-параметр `?page=N`
  (наряду с `?filter=...`).
- **Статический HTML**: в `leaderboard.html` вместо формы — панель с пометкой
  «Запустите `python tools/server.py` для записи вердиктов». Пагинацию истории
  делаем на JS, переключая видимость скрытых `<div class="history-page">`.
- **Пагинация**: page size = 20, page numbers. Для сервера — серверный slicing
  по `page` query; для статики — заранее генерируются N блоков по 20 записей
  и JS-переключалка.

## Risks / Trade-offs

- [Risk] `<details>` не анимируется, раскрытие резкое → [Mitigation] допустимо
  для технической панели; при желании можно добавить небольшой JS-аниматор позже.
- [Risk] Перенос фильтра над leaderboard слева уменьшает горизонтальное место
  → [Mitigation] фильтр узкий (`select` + `label` inline), оставляем в левой
  колонке.
- [Risk] История теперь не видна сразу → [Mitigation] один клик по заголовку,
  состояние свёрнуто/развёрнуто не сохраняется между перезагрузками.
