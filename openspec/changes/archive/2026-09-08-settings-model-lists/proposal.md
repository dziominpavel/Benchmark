## Why

На странице `/settings` карточка «Модели» показывает только счётчики
(«Всего в реестре», «Активных», «Неактивных (архив)») — по ним нельзя понять,
какие именно модели входят в каждую группу. Чтобы увидеть состав, приходится
уходить на `/add` или лидерборд.

## What Changes

- Строки «Активных» и «Неактивных (архив)» в карточке «Модели» становятся
  сворачиваемыми списками (нативный `<details>/<summary>`, без JS),
  по умолчанию свёрнутыми.
- В развёрнутом виде строка показывает все модели группы: имя + ELO,
  отсортированные по убыванию ELO. Имя — ссылка на `/model/<id>`.
- Пустая группа остаётся раскрываемой и показывает заглушку
  (например, «Нет неактивных моделей»).
- Строка «Всего в реестре» остаётся обычным счётчиком.
- Роут `settings_page` передаёт в шаблон списки моделей по группам
  (id, name, elo), а не только счётчики.

### New Capabilities

### Modified Capabilities

- `leaderboard-ui`: requirement «Страница настроек» — счётчики моделей
  становятся раскрываемыми списками моделей группы (имя + ELO, сортировка
  по ELO desc, ссылка на страницу модели, заглушка для пустой группы).

## Impact

- `tools/server.py`: шаблон `SETTINGS_TEMPLATE` (карточка «Модели»,
  строки ~1515–1531) и роут `settings_page` (~1890–1919) — передача
  списков моделей из `ensure_index()` вместо одних счётчиков.
- Поведение остальной части `/settings` (карточка «Таски», кнопка
  «+ Добавить модель») не меняется.
