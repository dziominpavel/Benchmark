## Why

Блок «Рекомендуемые модели к прогону» показывает пару, ELO и текстовую
причину («близкий рейтинг (разница 4)», «рематч (встречались 2 раза)» и т.п.).
Причины по ELO малоинформативны — оба рейтинга и так видны в карточке, — а
история личных встреч пары показывается только косвенно и только для рематчей.
Пользователь не видит, сколько раз модели встречались и с каким счётом.

## What Changes

- В карточку рекомендации добавляется строка личных встреч пары:
  `личные встречи: N · счёт A:B` — где `N` — число сыгранных вердиктов пары
  (текущий `pair_games`), `A:B` — счёт по победам в порядке отображения
  карточки (левая модель : правая). Ничьи в счёте НЕ выделяются.
- Для пары без общих вердиктов строка принимает вид
  `личные встречи: не встречались` (без счёта).
- **BREAKING** (на уровне спеки): поле `reason` и все ELO-/калибровочные
  формулировки причин удаляются из вывода `get_recommendations` и из
  карточки. Сортировка рекомендаций НЕ меняется (`pair_games` → тир →
  близость ELO).
- Статистика пары расширяется: помимо числа игр считаются победы каждой
  модели (для счёта серии). Аннулированные и tombstone-вердикты по-прежнему
  не учитываются.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `pairing-algorithm`: требование «Причина рекомендации» удаляется;
  требование «Вывод рекомендации» меняется — вместо `reason` добавляются
  поля статистики личных встреч (`pair_games`, победы по сторонам) и
  описание строки отображения.
- `leaderboard-ui`: требование «Блок рекомендаций» меняется — карточка
  показывает имя, ELO и строку личных встреч вместо причины.

## Impact

- `tools/server.py`: `get_pair_game_counts` → статистика пары (игры +
  победы по id), `get_recommendations` (новые поля, удаление `reason`),
  шаблон `INDEX_TEMPLATE` (строка `rec-reason` → строка личных встреч),
  CSS-класс.
- `tools/test_pairing.py`: мок счётчика пар и assert на причину «рематч»
  обновляются под новый формат.
- Спеки: `openspec/specs/pairing-algorithm/spec.md`,
  `openspec/specs/leaderboard-ui/spec.md`.
- Не затрагивается: сортировка рекомендаций, журнал `matchups/`,
  `generate_html.py` (статичный экспорт без рекомендаций).
