## MODIFIED Requirements

### Requirement: Редактирование в настройках

Страница `/settings` SHALL содержать сводку «Наличие ответов: закрыто X из Y, осталось N» со ссылкой на учёт, а сам учёт SHALL быть доступен либо секцией там же, либо отдельной страницей со ссылкой из настроек. Редактирование SHALL выполняться чекбоксами матрицы (строки — модели, столбцы — активные таски), сортировка строк по умолчанию — по имени модели (case-insensitive, по алфавиту); столбцы — по `id` таска. Матрица SHALL содержать фильтр строк по статусу модели «Показывать»: «Только активные» (по умолчанию) / «Все» / «Только неактивные», как фильтр таблицы рейтинга на главной. Фильтр SHALL применяться только к строкам; столбцы остаются только активными тасками. Сохранение SHALL быть одной кнопкой на всю матрицу и SHALL сохранять флаги моделей, скрытых фильтром, без изменений (по образцу сохранения флагов неактивных тасков). Bulk-действия SHALL включать «отметить строку», «отметить столбец» и фильтр «только долги».

#### Scenario: Строки по алфавиту

- **WHEN** открыта матрица при моделях `zebra` (0 долгов) и `alpha` (2 долга)
- **THEN** `alpha` выше `zebra`

#### Scenario: Должники сверху

- **WHEN** открыта матрица при `new-model` (2 долга) и `old` (0 долгов)
- **THEN** порядок определяется именем по алфавиту, а не числом долгов (сортировка «должники сверху» заменена алфавитной; долги видны в колонке «Долг» и фильтре «только долги»)

#### Scenario: Фильтр по умолчанию — только активные

- **WHEN** открыта секция «Наличие ответов» без параметров
- **THEN** показаны только модели со статусом `active`
- **AND** фильтр «Показывать» установлен в «Только активные»

#### Scenario: Фильтр только неактивные

- **WHEN** выбран фильтр «Только неактивные»
- **THEN** показаны только модели со статусом `archived` с пилюлей «неактивна»
- **AND** активные модели скрыты

#### Scenario: Фильтр все

- **WHEN** выбран фильтр «Все»
- **THEN** показаны активные и архивные модели в общем списке по алфавиту
- **AND** архивные помечены пилюлей «неактивна»

#### Scenario: Сохранение не теряет скрытые флаги

- **WHEN** координатор сохраняет матрицу в режиме «Только активные»
- **THEN** флаги архивных моделей в `data/answer_flags.yaml` сохраняются без изменений

#### Scenario: Фильтр только долги

- **WHEN** включён фильтр «только долги»
- **THEN** строки без false скрыты
- **AND** счётчик показывает «показано N из M моделей»
