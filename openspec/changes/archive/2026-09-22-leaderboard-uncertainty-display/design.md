## Context

См. `proposal.md` (why). Ограничения: формула ELO заморожена (`tools/elo.py` не трогаем), журнал `data/matchups/` append-only, `index.json v2` без новых полей, сортировка и медали топ-3 как в `tools/server.py:leaderboard`. См. спеки изменения: `specs/leaderboard-ui/spec.md`.

## Goals / Non-Goals

**Goals:**

- Один главный ELO + видимое доверие (`±`, `прогрев`) без второго рейтинга.
- Ноль миграций данных: всё считается при рендере.

**Non-Goals:**

- Смена `K`, симметризация дельт, Bradley-Terry/Glicko, пер-таск рейтинги.
- Новые поля в `index.json`, изменения `elo_history`, pairing-algorithm, coverage.

## Decisions

1. **`± = round(400 / sqrt(games))`, `0 игр → —`.** Эвристика порядка статошибки биномиальной доли в шкале ELO, а не строгий CI. Альтернатива — точный SE из Bradley-Terry — отвергнута: требует второго рейтинга, против решения из обсуждения.
2. **Счёт на лету в `leaderboard()`, не в `index.json`.** Хелпер `confidence_half_width(games)` рядом с `format_winrate` в `tools/render_helpers.py`, колонка в `INDEX_TEMPLATE`. Альтернатива — писать в индекс — отвергнута: лишний пересчёт и версионирование без пользы.
3. **Порог прогрева `<10` reuse.** Тот же порог, что `K=40` в `tools/elo.py:k_factor` и минимум для архивации в `data/models.yaml`. Новый порог не вводим.
4. **Легенда расширяется, таблица нетронута по сортировке.** Медали, фильтры `active/all/inactive`, `/stats`, `/model/<id>`, `/history` не меняются.

## Risks / Trade-offs

- [Эвристика, а не CI] `±` занижает/завышает истинную ошибку при несбалансированных соперниках → Митигация: легенда честно пишет формулу `400/√игр`, это индикатор объёма, не гарантия.
- [Перекрытие интервалов без вывода] Пользователь может всё равно читать порядок как строгий → Митигация: сценарий спеки фиксирует трактовку «перекрылись = шум».
- [Ширина таблицы] +1 колонка на узких экранах → Митигация: существующий скролл `.table-wrap`.

## Migration Plan

- Деплой: только `tools/server.py` + шаблон + `render_helpers.py`. Откат: убрать колонку, данные не менялись.
- Проверки: открыть `/` с текущим `index.json` (модели 4/13/19 игр), сверить `±200/±111/±92`, бейдж только при `<10`, сортировка по ELO без изменений.
