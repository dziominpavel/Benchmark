## Why

Сейчас пара моделей навсегда исключается из рекомендаций после первой же
игры (`get_all_matchup_pairs` возвращает бинарное множество «встречались /
не встречались»). Когда все C(n,2) пары будут прогнаны, блок рекомендаций
навсегда пустеет — хотя самый информативный следующий шаг для точности
рейтинга это рематчи самых близких по ELO пар: одна игра на пару — один
бросок монеты с весом, повторные встречи снимают дисперсию вердиктов.

## What Changes

- Учёт истории пар становится счётчиком: вместо `set` сыгранных пар —
  число игр каждой пары (данные уже есть в журнале `matchups/*/`,
  миграции не требуется).
- Пары перестают исключаться из кандидатов; сортировка рекомендаций
  становится трёхуровневой: число игр пары (по возрастанию) → тир
  калибровки → близость ELO. Несыгранные пары (0 игр) всегда выше
  рематчей, поведение до завершения круга не меняется.
- Причина рекомендации для уже игравших пар получает формулировку
  рематча с числом прошлых встреч.
- Плашка «Все пары уже прогнаны…» заменяется, т.к. при ≥2 активных
  моделях кандидаты есть всегда.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `pairing-algorithm`: меняется требование «Источник кандидатов»
  (пара больше не исключается навсегда), требование «Тиры калибровки и
  сортировка» (новый первичный ключ — число игр пары), требование
  «Причина рекомендации» (причина для рематча) и сценарий «Нет
  несравнённых пар» требования «Вывод рекомендации».
- `leaderboard-ui`: в требовании «Блок рекомендаций» убирается ветка
  с плашкой «Все пары уже прогнаны…» — при ≥2 активных моделях
  рекомендации есть всегда (рематчи).

## Impact

- `tools/server.py`: `get_all_matchup_pairs` → счётчик игр на пару,
  сортировка и тексты причин в `get_recommendations`, текст пустого
  состояния в `INDEX_TEMPLATE`.
- `openspec/specs/pairing-algorithm/spec.md`: дельта-требования.
- `tools/test_pairing.py`: покрытие рематч-логики.
- Нет обратно-несовместимых изменений: до исчерпания несыгранных пар
  рекомендации идентичны текущим; журнал `matchups/` не меняется.
