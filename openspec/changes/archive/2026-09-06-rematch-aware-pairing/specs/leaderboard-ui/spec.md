## MODIFIED Requirements

### Requirement: Блок рекомендаций

Блок «Рекомендуемые модели к прогону» SHALL показывать одну пару
(первую из топ-3 pairing-algorithm: имя, ELO, причина) с кнопкой
«Прогнать», подставляющей пару в форму вердикта и прокручивающей
к ней. Остальные пары SHALL листаться кнопкой «→» (счётчик «N / M»,
листание по кругу через `showRec`/`nextRec`). Плашка «Все пары уже
прогнаны…» SHALL NOT показываться: при ≥2 активных моделях кандидаты
есть всегда (после полного круга предлагаются рематчи).

#### Scenario: Отображение рекомендации

- **WHEN** есть пары-кандидаты (несыгранные или рематчи)
- **THEN** блок показывает первую пару топ-3 с причиной
- **AND** кнопка «→» показывает следующую, кнопка «Прогнать» заполняет dropdowns формы

#### Scenario: Рекомендации после полного круга

- **WHEN** все пары моделей уже сравнивались хотя бы раз
- **THEN** блок показывает рематчи из топ-3 с причиной «рематч (встречались N раз)»
- **AND** плашка «Все пары уже прогнаны…» не отображается
