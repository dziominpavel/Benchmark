# Spec Delta

## MODIFIED Requirements

### Requirement: Блок аналитики «Динамика ELO»

Карточка SHALL показывать ломаные выбранных моделей: по своим матчам в
хронологическом порядке `seq`, общая шкала времени — матчи выбранных моделей;
опорная линия 1200 и легенда с текущим ELO каждой линии. Выбор SHALL
задаваться одним текстовым полем со списком моделей и отображаться чипами
разбора (см. «Разбор списка моделей в карточке «Динамика ELO»»); карточка
SHALL NOT перечислять по одному контролу выбора на каждую модель реестра и
SHALL NOT содержать отдельного поля поиска по реестру. Порядок линий SHALL
совпадать с порядком токенов списка; одновременно не более 10 моделей.
При отсутствии параметра `lines` SHALL применяться топ-5 активных по ELO; при
наличии параметра, который не разбирается, карточка SHALL показывать пустое
состояние без подмены. Пресеты «Топ-5»/«Топ-10» SHALL оставаться доступными и
SHALL показывать свой состав до применения. Период `period` — 30/90/всё (по
умолчанию 90) SHALL фильтровать матчи по дате. Линия каждой модели SHALL быть
кликабельна и вести в профиль модели (`/model/<id>`); хит-областью линии
служит прозрачная полоса по ломаной, включая точку её конца.

#### Scenario: Состояние по умолчанию

- **WHEN** пользователь открывает `/stats` без параметров
- **THEN** показаны линии топ-5 активных моделей за 90 дней

#### Scenario: Выбор моделей по URL

- **WHEN** URL содержит `lines=<id1>,<id2>`
- **THEN** показаны линии этих моделей

#### Scenario: Период 30 дней

- **WHEN** URL содержит `period=30`
- **THEN** в линии попадают только матчи последних 30 дней
- **AND** шкала времени подписана датами окна

#### Scenario: Лимит линий

- **WHEN** в `lines` перечислено 12 моделей
- **THEN** показаны 10 линий — первые 10 в порядке перечисления
- **AND** карточка сообщает, какие две модели не вошли

#### Scenario: Нет матчей в периоде

- **WHEN** у выбранных моделей нет матчей в периоде
- **THEN** карточка показывает пустое состояние

#### Scenario: Слепок без выбора моделей

- **WHEN** зеркало показывает «Динамику ELO»
- **THEN** контролы выбора моделей и переключатель периода не отображаются
- **AND** видно состояние по умолчанию (топ-5, 90 дней)

#### Scenario: Переход в профиль по линии

- **WHEN** пользователь кликает по линии модели (по ломаной или точке её конца)
- **THEN** открывается `/model/<id>`

#### Scenario: Выбор без JavaScript

- **WHEN** JavaScript отключён
- **THEN** выбор линий задаётся текстовым полем со списком моделей (имена или `id` через запятую), и та же форма применяет выбор
- **AND** перечисления всех моделей реестра на странице нет
- **AND** подсказки и живая проверка разбора не отображаются

#### Scenario: Список не разбирается

- **WHEN** URL содержит `lines=<токен, которого нет в реестре>`
- **THEN** карточка показывает пустое состояние
- **AND** подмена на топ-5 активных моделей не выполняется

#### Scenario: Состав пресета до применения

- **WHEN** пользователь открывает карточку «Динамика ELO»
- **THEN** рядом с пресетами «Топ-5» и «Топ-10» указаны имена моделей, которые попадут в набор

## ADDED Requirements

### Requirement: Разбор списка моделей в карточке «Динамика ELO»

Список моделей SHALL разбираться по токенам через запятую в порядке: `id`
реестра, точное имя, однозначная подстрока имени, однозначная подстрока `id`.
Нераспознанный токен SHALL показываться как «не найдено», неоднозначный — как
«неоднозначно» со списком кандидатов; токены SHALL NOT отбрасываться молча.
Параметр `lines` SHALL принимать имена и `id` и SHALL хранить канонические
`id` выбранных моделей; при неразобранных токенах или отброшенных моделях
исходный текст списка SHALL сохраняться без канонизации. Поле SHALL
отображать имена моделей, а не внутренние `id`.

#### Scenario: Точное имя модели

- **WHEN** в списке указано имя «Cursor Fable 5.1 1M Max»
- **THEN** выбрана модель `cursor-fable-5-1-1m-max`

#### Scenario: Однозначная часть имени

- **WHEN** в списке указан токен «fable», которому соответствует ровно одна модель
- **THEN** выбрана эта модель

#### Scenario: Неоднозначный токен

- **WHEN** в списке указан токен, которому соответствуют несколько моделей
- **THEN** токен показан как неоднозначный со списком кандидатов
- **AND** линии этих моделей не строятся

#### Scenario: Ненайденный токен

- **WHEN** в списке указан токен, которому не соответствует ни одна модель
- **THEN** токен показан как «не найдено»
- **AND** выбор не подменяется другими моделями

#### Scenario: Повтор одного токена

- **WHEN** один и тот же токен указан дважды
- **THEN** модель выбрана один раз, на позиции первого вхождения

#### Scenario: Имена в URL

- **WHEN** URL содержит `lines=` с именем модели
- **THEN** выбрана соответствующая модель
- **AND** в URL ответа параметр `lines` содержит её `id`

#### Scenario: Текст с промахом не канонизируется

- **WHEN** URL содержит `lines=` с неразобранным токеном
- **THEN** параметр `lines` сохраняет исходный текст списка
- **AND** неразобранный токен показан как «не найдено»

#### Scenario: Поле показывает имена

- **WHEN** выбраны модели
- **THEN** текстовое поле содержит их имена, а не внутренние `id`

### Requirement: Подсказки и живая проверка списка моделей

Поле SHALL предлагать подсказки реестра по последнему введённому токену; выбор
подсказки SHALL подставлять модель в список. Разбор SHALL пересчитываться при
каждом изменении поля без перезагрузки страницы, а расхождение разбора с
применённым выбором SHALL показываться пометкой. Без JavaScript подсказки и
живая проверка SHALL NOT отображаться, а форма SHALL применять выбор обычной
отправкой.

#### Scenario: Подсказка по токену

- **WHEN** пользователь набирает в поле часть имени модели
- **THEN** появляются подходящие модели с их ELO

#### Scenario: Подстановка из подсказки

- **WHEN** пользователь выбирает модель из подсказки
- **THEN** её имя добавлено в список поля

#### Scenario: Живая проверка разбора

- **WHEN** в поле введён токен, которому не соответствует ни одна модель
- **THEN** без перезагрузки страницы появляется пометка «не найдено»

#### Scenario: Изменения не применены

- **WHEN** разбор поля отличается от применённого выбора
- **THEN** рядом с кнопкой «Показать» показана пометка «не применено»

#### Scenario: Без JavaScript

- **WHEN** JavaScript отключён
- **THEN** подсказки и живая проверка разбора не отображаются
- **AND** форма применяет выбор отправкой
