# Proposal

## Why

Ручной выбор моделей в карточке «Динамика ELO» на `/stats` сломан: поле
принимает только внутренние `id`, любой другой ввод молча отбрасывается, а
пустой или нераспознанный ввод без предупреждения подменяется топ-5 — вместо
своего набора пользователь видит чужой график. Три контрола на одно состояние
(чипы, «id через запятую», «Поиск по реестру»), из которых последний без
JavaScript вообще не работает, и молчаливая подмена делают выбор моделей самым
непрозрачным местом консоли.

## What Changes

- Один контрол выбора вместо трёх: текстовое поле со списком моделей, где
  токен — это `id`, точное имя или однозначная часть имени. Отдельное поле
  «Поиск по реестру» убирается, поиск живёт внутри того же поля как подсказки
  по последнему токену.
- Серверный разбор токена: `id` → точное имя → однозначная подстрока имени →
  однозначная подстрока `id`. Неоднозначные и ненайденные токены
  показываются пользователю (неоднозначные — с кандидатами) вместо молчаливого
  отбрасывания.
- Молчаливый подмены нет: параметр `lines` присутствует, но не разбирается —
  пустое состояние карточки; параметра нет — дефолт «топ-5 активных по ELO».
- Порядок выбранных моделей = порядок ввода. Сейчас лишние модели
  отбираются по ELO и набор молча переставляется; при числе моделей больше
  лимита карточка сообщает, какие не вошли.
- Поле выбора отображается именами моделей, а не внутренними слагами: ручной
  список остаётся читаемым после перезагрузки страницы.
- Пресеты «Топ-5»/«Топ-10» показывают свой состав до применения.
- URL-параметр `lines` хранит канонические `id` выбранных моделей; сервер
  принимает в нём и имена, и `id`.
- Один серверный эндпоинт разбора списка — общий источник правды для рендера
  страницы, подсказок в поле и живой проверки в браузере.

## Capabilities

### New Capabilities

- _(нет)_

### Modified Capabilities

- `leaderboard-ui`: требование «Блок аналитики «Динамика ELO»» (состав
  контролов, пределы, порядок, пустое состояние, пресеты) и новые требования
  «Разбор списка моделей в карточке «Динамика ELO»» и «Подсказки и живая
  проверка списка моделей».

## Impact

- `tools/render_helpers.py`: `parse_lines_param` заменяется резолвером списка
  токенов; `default_line_ids` не меняется.
- `tools/server.py`: роут `/stats` (разбор списка, канонизация URL, пустое
  состояние, пресеты с составом), шаблон `STATS_TEMPLATE`, эндпоинт разбора
  списка.
- `tools/static/js/lines-picker.js`: переработка — одно поле, подсказки по
  токену, живая проверка разбора.
- `tools/static/css/console.css`: стили `.lines-*`.
- Тесты: `tools/test_analytics.py`, `tools/test_data_cache.py` (сценарии
  `/stats`), при необходимости `tools/test_export.py` (слепок).
- Спека: `openspec/specs/leaderboard-ui/spec.md` (MODIFIED + ADDED).
- Формат журнала, формула ELO, `data/index.json`, экспорт и статический слепок
  не меняются: слепок по-прежнему показывает «Динамику ELO» в состоянии по
  умолчанию (топ-5, 90 дней) без контролов.
