## 1. Подготовка

- [x] 1.1 Создать директорию `logs/` и зафиксировать `logs/.gitkeep` в git, чтобы папка для журналов существовала из коробки.

## 2. Скрытый лаунчер

- [x] 2.1 Создать `launch.vbs`: создавать `logs/` при отсутствии, запускать `python tools/server.py` в скрытом процессе с перенаправлением `stdout`/`stderr` в `logs/server.log`, фиксировать PID в `logs/server.pid`, ждать 2 секунды и открывать `http://localhost:5000`. Проверить: после запуска `launch.vbs` появляются `logs/server.log` и `logs/server.pid`, сервер доступен по `http://localhost:5000`, консоль не видна.
- [x] 2.2 Изменить `start.bat`: перейти в папку репозитория, вызвать `launch.vbs` и сразу завершиться. Проверить: двойной клик по `start.bat` — консоль мелькает и закрывается, окно не остаётся висеть, браузер открывается.

## 3. Остановка

- [x] 3.1 Создать `stop.bat`: читать `logs/server.pid` и завершать процесс `taskkill /PID <pid> /F`; если PID-файла нет — выводить сообщение, что сервер не запущен. Проверить: после запуска `start.bat` двойной клик по `stop.bat` останавливает сервер, порт 5000 освобождается.

## 4. Интеграция

- [x] 4.1 Запустить `start.bat`, открыть leaderboard, записать пробный вердикт через веб-UI и убедиться, что `tools/server.py` работает как раньше.
- [x] 4.2 Остановить сервер `stop.bat` и снова запустить `start.bat` без ручного освобождения порта.
