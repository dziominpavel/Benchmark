# Design

## Context

См. `proposal.md` — Why. Оболочка страниц живёт в `tools/templates/shell.html`
(шапка, подвал), страница настроек — в `SETTINGS_TEMPLATE` внутри
`tools/server.py`. Сервер запускается локально из исходников (`start.bat`,
`.venv`), есть режим «только просмотр» для статического слепка витрины
(`tools/export_web.py`). Релизный трек (`docs/versioning.md`): версия — тег
последнего релиза `vX.Y.Z`, промежуточных версий нет; счётчики сборок
запрещены. Холодный старт главной измеряется в `tools/test_perf.py`
(бюджет 0.5 с) — git-подпроцессы на пути запроса недопустимы.

## Goals / Non-Goals

**Goals:**

- Одна точка резолва метаданных (версия, сборка) для живого сервера и слепка.
- Никаких git-подпроцессов на пути HTTP-запроса.
- Корректная работа без git (архив исходников) и скрытие блоков без источников.

**Non-Goals:**

- Счётчик сборок и версия из числа коммитов — запрещены `docs/versioning.md`.
- Хеш коммита, статус рабочего дерева, время запуска процесса — не показываем.

## Decisions

- **Резолв — константы модуля при импорте.** `_APP_VERSION`/`_APP_BUILD_TIME`
  считаются один раз в `tools/server.py`; шаблоны получают jinja-глобалы
  `app_version()`/`app_build_time()`. Альтернатива — резолв в каждом запросе —
  отклонена: два git-подпроцесса на запрос при бюджете холодной главной.
  Плата: значение актуально на момент старта процесса, после нового коммита
  обновляется перезапуском.
- **Версия — `git describe --tags --abbrev=0`** с нормализацией к `vX.Y.Z`;
  фолбэк — `version` из `pyproject.toml` (клон без тегов, архив). Оба
  источника приводятся к одной форме, чтобы UI не смешивал «0.3.0» и «v0.3.0».
- **Сборка — время последнего коммита** (`git show -s --format=%cI HEAD`
  в локальной зоне, формат `ДД.ММ.ГГГГ ЧЧ:ММ`). Даёт различимость запусков
  одной версии (коммиты после релиза). Фолбэк без git — время файла
  `pyproject.toml` (у архива GitHub близко к времени сборки архива).
- **Общий помощник `_run_git`.** Оба резолвера вызывают `subprocess.run`
  с `CREATE_NO_WINDOW` (скрытый запуск через `launch.vbs` не мигает консолью)
  и таймаутом 5 с; вывод нормализуется (`strip`), ошибки — `None`.
- **Места вывода: подвал всех страниц и секция «О консоли» настроек.**
  Шапка отклонена владельцем (перегружена навигацией). Подвал виден на всех
  страницах, включая формы; настройки — «паспорт» запущенного инстанса.
  В слепке витрины значения запекаются автоматически: `export_web` рендерит
  те же страницы тем же шаблоном.
- **Скрытие блоков без источников.** Пустое значение → `{% if %}` в подвале
  и «—» в карточке настроек; разметка не ломается.

## Risks / Trade-offs

- [Долгоживущий процесс после нового коммита показывает старую сборку] →
  ожидаемо: метка фиксируется при старте, перезапуск её обновляет.
- [Два git-подпроцесса при импорте (~десятки мс)] → однократно и вне запроса;
  бюджеты `test_perf.py` измеряют обработку запроса, не импорт.
- [В каталоге без git и без `pyproject.toml` обе метки пусты] → сценарий
  «Источники недоступны» спеки: блоки скрыты, страница отрисовывается.
- [Слепок витрины запекает значения на момент экспорта] → согласовано
  с существующей строкой подвала «данные на момент сборки слепка».
