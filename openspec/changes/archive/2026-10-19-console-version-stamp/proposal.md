# Proposal

## Why

Версия консоли нигде в UI не видна: по скриншоту страницы или в обсуждении
ошибки нельзя понять, какой релиз и какая сборка запущены. Владельцу нужны обе
метки — версия (тег последнего релиза) и дата-время сборки — в предсказуемых
местах: раздел настроек и низ любой страницы. Шапка как место для метаданных
отклонена: она перегружена навигацией, а подвал и настройки стабильны.

## What Changes

- **Подвал всех страниц** (`shell.html`): после названия консоли — маркер
  версии (тег релиза `vX.Y.Z`) и маркер сборки («сборка ДД.ММ.ГГГГ ЧЧ:ММ»);
  каждый блок скрывается, если источника нет. Работает и в статическом слепке
  витрины — значения запекаются на момент экспорта.
- **Страница `/settings`**: новая секция «О консоли» (карточка `id="about"`,
  пункт в локальной навигации) — те же версия и сборка в виде пар
  «подпись → значение» и подсказка о происхождении значений.
- **Резолверы метаданных** в `tools/server.py`:
  - версия — тег ближайшего релиза (`git describe --tags --abbrev=0`),
    нормализация к `vX.Y.Z`, фолбэк — `version` из `pyproject.toml`;
  - сборка — время последнего коммита (`git show -s --format=%cI`) в локальной
    зоне, фолбэк — время файла версии проекта;
  - резолв один раз при импорте модуля (вне пути запроса), `CREATE_NO_WINDOW`
    для скрытого запуска через `launch.vbs`.
- **Тесты**: `test_version_badge` в `tools/test_data_cache.py` (подвал всех
  страниц live и read-only, секция настроек, нормализация, приоритет git над
  файлом, скрытие без источников, формат даты-времени); маркеры в подвале
  слепка — `tools/test_export.py`. Пункт `CHANGELOG.md` в `[Unreleased]`.

## Capabilities

### New Capabilities

Нет: изменение развивает существующую глобальную оболочку консоли.

### Modified Capabilities

- `console-shell`: новое требование «Версия и дата-время сборки консоли» —
  маркеры в подвале всех страниц, секция «О консоли» настроек, значения
  в слепке витрины, фолбэки и скрытие блоков без источников.

## Impact

- `tools/server.py` — `app_version()`/`resolve_app_version()`,
  `app_build_time()`/`resolve_build_time()` и jinja-глобалы; секция
  «О консоли» в шаблоне настроек; `_run_git` — общий вызов git.
- `tools/templates/shell.html` — маркеры `.footer-version`/`.footer-build`.
- `tools/static/css/console.css` — стили `.about-meta`/`.about-row`
  и числовая типографика метаданных подвала.
- Тесты: `tools/test_data_cache.py` (`test_version_badge`),
  `tools/test_export.py` (маркеры в слепке).
- `CHANGELOG.md` — пункт `[Unreleased]`.
- Данные и контракты не меняются: новые значения только читаются из git
  и файла версии, `index.json` и журнал не затрагиваются.
