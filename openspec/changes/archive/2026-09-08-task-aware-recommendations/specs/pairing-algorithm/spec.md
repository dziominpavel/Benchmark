## MODIFIED Requirements

### Requirement: Вывод рекомендации

Система SHALL возвращать не более 3 пар (`top_n=3`), отсортированных по `pair_games`, затем по тиру, затем по убыванию score. Каждая запись содержит: `model_a`, `model_b`, имена, `elo_a`, `elo_b`, `elo_diff`, `pair_games`, `pair_wins_a`, `pair_wins_b`, `h2h_label`, `tier`, `score`, `recommended_task`. Поле `reason` SHALL NOT возвращаться. `h2h_label` SHALL иметь вид «личные встречи: N · счёт A:B» для сыгранной пары (N = `pair_games`, A:B = `pair_wins_a`:`pair_wins_b` — победы в порядке `model_a`, затем `model_b`) и «личные встречи: не встречались» для несыгранной. `recommended_task` SHALL быть первым активным таском в лексикографическом порядке `T-NNN`, для которого у пары отсутствует неаннулированный вердикт; если для пары заполнены все активные таски, `recommended_task` SHALL быть первым активным таском. Блок «Рекомендуемые модели к прогону» показывает имя, ELO, `h2h_label` и `recommended_task`; кнопка «Прогнать» подставляет пару в форму вердикта.

#### Scenario: Отображение рекомендации
- **WHEN** есть активные пары-кандидаты (моделей ≥ 2)
- **THEN** пользователь видит до 3 карточек «Имя (ELO) vs Имя (ELO) | строка личных встреч | таск: T-NNN"

#### Scenario: Строка для сыгранной пары
- **WHEN** пара A-B встречалась 2 раза со счётом побед 1:1
- **THEN** `h2h_label` — «личные встречи: 2 · счёт 1:1»

#### Scenario: Строка для несыгранной пары
- **WHEN** пара A-B не встречалась (`pair_games = 0`)
- **THEN** `h2h_label` — «личные встречи: не встречались»
- **AND** счёт в строке не показывается

#### Scenario: Все пары сыграны
- **WHEN** все возможные пары уже сравнены (у всех pair_games ≥ 1)
- **THEN** блок продолжает показывать топ-3 — рематчи с наименьшим `pair_games` и наименьшим elo_diff
- **AND** плашка «Все пары уже прогнаны…» SHALL NOT отображаться

#### Scenario: Нет несравнённых пар
- **WHEN** все возможные пары уже сравнены (при ≥ 2 активных моделях)
- **THEN** рекомендации НЕ пусты — возвращаются рематчи по общей сортировке (минимальный `pair_games`, затем тир, затем близость ELO)

#### Scenario: Рекомендуемый таск — первый пустый
- **WHEN** активны таски `T-001` и `T-002`, у пары A-B нет вердиктов
- **THEN** `recommended_task` равен `T-001`

#### Scenario: Рекомендуемый таск — следующий пустой
- **WHEN** у пары A-B есть вердикт в `T-001` и нет вердикта в `T-002`
- **THEN** `recommended_task` равен `T-002`

#### Scenario: Рекомендуемый таск при полном покрытии
- **WHEN** у пары A-B есть вердикты во всех активных тасках
- **THEN** `recommended_task` равен первому активному таску
