## Context

См. `proposal.md` (Why): таблице рейтинга не хватает вида формы пула. Текущее состояние: главная (`tools/server.py`, `INDEX_TEMPLATE`) уже содержит прогресс, таблицу на 20 строк и сайдбар с вердиктом — добавлять туда еще график значит толкать форму вердикта вниз, а на мобиле (одна колонка до 900px) график вообще уедет из видимости. Для одиночной динамики уже есть паттерн серверного SVG без JS-библиотек (`build_elo_svg` в `tools/render_helpers.py`, CSS-классы `.card` / `.chart-*`). Данные бесплатны: `ensure_index()` отдает `index.json` со всеми Elo. Прототип на matplotlib (гистограмма + бар-лидерборд, `n=20, среднее=1199`) показал два урока: бары от нуля сжимают различия, а 8 бинов на 20 точках дают «пилу» вместо формы.

## Goals / Non-Goals

**Goals:**

- Отдельная страница `/stats` с первой карточкой «Распределение Elo», консистентная с темной темой и существующими карточками.
- Strip/dot-plot как честный первичный слой при малом `n`; сводка средним/медианой/порогом 1200.

**Non-Goals:**

- Интерактивный слайдер порога удаления («что если резать по X») — отдельная итерация.
- Блоки 2+ (Elo vs игры, винрейт vs Elo) и маркер «ты здесь» на странице модели — следующие итерации, место под них только зарезервировать структурой.
- Клиентские JS-графики и новые зависимости.

## Decisions

1. **Отдельный роут `/stats`, а не секция главной.** Альтернатива — collapsible-карточка под таблицей. Отклонена: главная перегружена, сайдбар выравнивается по высоте карточки рейтинга, новый блок сломает этот баланс; отдельная страница масштабируется блоками без редизайна главной.
2. **Серверный SVG-хелпер рядом с `build_elo_svg`, без библиотек.** Альтернатива — matplotlib/PNG или Chart.js. Отклонены: matplotlib нет в зависимостях сервера (только Flask + stdlib), PNG — бинарный артефакт без ресайза, JS-либы — новый класс рисков (CSP, офлайн). SVG переиспользует `.chart-grid` / `.chart-tick` / `.chart-dot`.
3. **Первичный слой — горизонтальные бары по моделям (имя + значение), strip-plot отклонен.** Первая версия со strip/dot-plot проверена на скриншоте: при `n=20` точки без подписей нечитаемы («просто точки»). Бары повторяют проверенный matplotlib-прототип: каждая модель опознаваема. Гистограмма не нужна — бары уже показывают форму.
4. **Ось от `min − паддинг`, линии 1200 / среднее, раскраска ниже/выше 1200.** Урок прототипа: ось от нуля убивает различия (все бары 1000+). Медиана убрана по решению пользователя — шумела рядом со средним. Цвета — из существующей семантики (красный/зеленый как `.l`/`.w`), а не новая палитра.
5. **Фильтр `active/all` query-параметром, по умолчанию `active`.** Консистентно с фильтром таблицы (`?filter`) и матрицей ответов (`?answer_filter`): архивные иначе тянут среднее и форму. Счетчики среднего/медианы/ниже-1200 считает роут из `index_data`, не клиент.
6. **Навигация: ссылка «Аналитика» в шапке главной + «Назад к рейтингу» на `/stats`.** Альтернатива — только URL без ссылки. Отклонена: страница без входа — мертвая страница; паттерн уже есть у `/history`.

## Risks / Trade-offs

- [Малый пул врет] Гистограмма на 20 точках выглядит значимее, чем есть → митигация: точки первичны, бины если и есть — полупрозрачный фон; в сводке явное `N`.
- [Новички с `K=40` и 3 играми выглядят наравне с ветеранами] → митигация: в тултипе/подписи точки показывать число игр; блок «Elo vs игры» во второй итерации закроет это системно.
- [Рассинхрон фильтров главной и `/stats`] → митигация: независимые query-параметры, дефолты задокументированы в спеке; общий хелпер фильтра при росте — позже.
- [Рост страницы в свалку блоков] → митигация: каждая карточка — независимый блок с якорем; новые блоки только карточками, без трогания блока распределения.
