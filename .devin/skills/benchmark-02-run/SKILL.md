Прогон модели на задаче бенчмарка — подготовка промпта для модели-участника.

**Когда использовать:** когда задача создана (через @benchmark-01-gen-task)
и нужно прогнать модель на ней.

## Шаги

1. **Определи задачу и модель:**
   - Пользователь указывает: `@benchmark-02-run <model-id> [task-id]`
   - Если task-id не указан — спроси, какая задача (или используй последнюю созданную)
   - Проверь, что задача существует: `tasks/T-NNN-<slug>/task.md`
   - Проверь, что модель зарегистрирована в `models.yaml`
     (если нет — предложи: `python tools/register_model.py --auto --id <slug> --name "<name>"`)

2. **Прочитай task.md:**
   ```bash
   cat tasks/T-NNN-<slug>/task.md
   ```
   Извлеки: id, title, project, baseline_commit, описание, критерии, ограничения.

3. **Сформируй промпт для модели:**

   Если задача связана с проектом (есть project + baseline_commit):
   ```
   Ты — участник бенчмарка LLM-моделей. Твоя задача — проанализировать проект
   и написать максимально полный ответ.

   ## Задача: <title>

   <содержание task.md — описание, критерии, ограничения>

   ## Инструкция

   1. Перейди в папку проекта:
      cd C:/projects/<project>
      git checkout <baseline_commit>

   2. Изучи код проекта согласно задаче.

   3. Напиши ответ в файл:
      C:/projects/Benchmark/answers/<task-id>/<model-id>.md

   Формат ответа — Markdown с front matter:
   ---
   task: <task-id>
   model: <model-id>
   date: <YYYY-MM-DD>
   ---

   Затем — разделы: Анализ, Находки (с указанием файла:строки и кодом),
   План (если требуется), Дополнительные находки.

   Код вставляй в блоки ```kotlin (или другой язык).
   UI-тексты на русском, код и идентификаторы на английском.

   Ответ должен быть максимально полным: все граничные случаи,
   все найденные проблемы, с кодом исправлений где применимо.
   ```

   Если задача абстрактная (без project/baseline_commit):
   ```
   Ты — участник бенчмарка LLM-моделей. Твоя задача — написать
   максимально полный ответ.

   ## Задача: <title>

   <содержание task.md>

   ## Инструкция

   Напиши ответ в файл:
   C:/projects/Benchmark/answers/<task-id>/<model-id>.md

   Формат ответа — Markdown с front matter:
   ---
   task: <task-id>
   model: <model-id>
   date: <YYYY-MM-DD>
   ---

   Затем — разделы: Анализ, Находки, План (если требуется).
   Код вставляй в блоки ```. Ответ должен быть максимально полным.
   ```

4. **Выведи промпт для пользователя:**
   - Покажи готовый промпт
   - Скажи: "Вставь этот промпт в чат с моделью <model-id>"
   - После ответа модели скажи: "Готово" — я проверю файл

5. **После "Готово":**
   - Проверь, что файл `answers/<task-id>/<model-id>.md` существует
   - Если да: "✓ Ответ сохранён. Дальше: @benchmark-02-run <другая-модель> <task-id>"
   - Если нет: "Файл не найден. Убедись, что модель сохранила ответ."

## Правила

- **Один прогон за раз** — одна модель на одной задаче
- **Модель пишет MD-ответ** — не код в проекте, а анализ + код в блоках
- **baseline_commit** — если есть, модель делает git checkout перед анализом
- **Путь к ответу** — `answers/<task-id>/<model-id>.md`
