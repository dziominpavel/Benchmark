Диалоговая генерация задачи бенчмарка — по одной за раз.

**Когда использовать:** когда нужно создать новую задачу для бенчмарка.
Пользователь описывает тему → ты предлагаешь формулировку → он утверждает →
файл создаётся.

## Шаги

1. **Определи тему из запроса пользователя:**
   - Что нужно проанализировать / найти / спланировать
   - Связана ли задача с реальным проектом (GymProgress, VoiceMind, Wishlot, ...)
     или это абстрактная задача
   - Если неясно — спроси

2. **Определи baseline_commit (опционально):**
   - Если задача связана с реальным проектом:
     ```bash
     cd C:/projects/<Project>
     git rev-parse HEAD
     ```
     Зафиксируй хеш в task.md (для воспроизводимости).
   - Если абстрактная задача — baseline_commit не нужен.

3. **Сгенерируй следующий ID:**
   - Посмотри `tasks/` какие уже есть (T-001, T-002, ...)
   - Следующий: `T-NNN-<slug>` (например `T-003-analyze-auth-module`)

4. **Предложи формулировку задачи** (покажи пользователю):
   - Заголовок
   - Описание (что проанализировать / найти / спланировать)
   - Контекст (модуль, файлы, проект — если применимо)
   - Критерии полноты ответа (конкретные, измеримые)
   - Ограничения (если есть)

5. **Жди утверждения:**
   - Пользователь: "добро" → создавай файл
   - Пользователь: "измени X" → обнови формулировку, снова спроси

6. **Создай файл:**
   ```
   tasks/T-NNN-<slug>/task.md
   ```
   По шаблону `tasks/_TEMPLATE.md`. Front matter:
   ```yaml
   ---
   id: T-NNN
   title: "<Заголовок>"
   project: "<ProjectName>"        # опц., если связана с проектом
   baseline_commit: "<hash>"       # опц., если связана с проектом
   ---
   ```

7. **Сообщи:**
   ```
   ✓ tasks/T-NNN-<slug>/task.md создан
   Дальше: @benchmark-02-run <model-id> — прогнать модель на этой задаче
   ```

## Правила

- **По одной задаче за раз** — не создавай несколько файлов сразу
- **Единый формат** — аналитика + код в MD-ответе (не кодописательство)
- **baseline_commit опционален** — только для задач с реальным проектом
- **Утверждение обязательно** — не создавай файл без "добро" от пользователя
- **UI-тексты на русском**, код и идентификаторы на английском
