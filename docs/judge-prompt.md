# Шаблон промпта судьи

> Скопируй этот промпт в чат с любой LLM. Дай два файла ответов.
> Судья не знает, какие это модели — сравнение анонимно.

---

## Промпт

```
Ты — судья в бенчмарке LLM-моделей. Твоя задача — сравнить два ответа
на одну и ту же задачу и выбрать победителя.

## Задача

[Вставь содержимое tasks/T-NNN/task.md]

## Answer 1

[Вставь содержимое первого файла ответа]

## Answer 2

[Вставь содержимое второго файла ответа]

## Критерии сравнения

Оцени по следующим критериям:

1. **Полнота** — все ли требования задачи покрыты, все ли граничные случаи рассмотрены
2. **Точность** — правильность анализа, корректность найденных проблем
3. **Качество кода** — если есть код в ответе, насколько он корректен и идиоматичен
4. **Структура** — насколько ответ хорошо организован, легко ли его читать
5. **Глубина** — насколько глубоко проанализирована проблема, есть ли неочевидные находки

## Правила

- Выбери **одного победителя**: Answer 1 или Answer 2
- Ничья — только в **действительно спорных** случаях, когда ответы практически
  одинаково хороши. Это должно быть редким исключением
- Даже если оба ответа справились с задачей, выбери того, кто сделал это лучше
- Не предполагай, какие это модели — сравнивай только по содержанию

## Формат ответа

1. Оценка по каждому критерию (1-10) для каждого ответа
2. Общая оценка (сумма или среднее) для каждого ответа
3. Победитель: Answer 1 или Answer 2 (или Ничья)
4. Обоснование: 2-3 предложения, почему победитель лучше

Пример:
```
Answer 1: полнота 8, точность 9, код 8, структура 7, глубина 8 = 40/50
Answer 2: полнота 7, точность 7, код 7, структура 8, глубина 6 = 35/50

Победитель: Answer 1

Обоснование: Answer 1 нашёл на 2 бага больше, включая неочевидный
граничный случай с пустым списком. Код исправления более идиоматичен.
Answer 2 лучше структурирован, но менее глубокий анализ.
```
```

## Как использовать

1. Скопируй промпт выше
2. Замени `[Вставь содержимое tasks/T-NNN/task.md]` на содержимое задачи
3. Замени `[Вставь содержимое первого файла ответа]` на первый ответ
4. Замени `[Вставь содержимое второго файла ответа]` на второй ответ
5. Вставь в чат с любой LLM
6. Прочитай ответ судьи
7. Запиши вердикт в веб-UI (localhost:5000)

## Какие ответы давать судье

- Судья получает **анонимные** ответы (Answer 1, Answer 2)
- Не сообщай судье, какие это модели
- Судья не видит ELO, предыдущие вердикты, или другую контекстную информацию
- Только: задача + 2 ответа
